SKILLS RECOMENDADAS PARA O CLAUDE CODE

1. PRODUCT-DISCOVERY

Objetivo:
Ajudar a transformar a ideia em requisitos claros.

Deve ajudar a criar:

- Personas.
- Jornada do usuário.
- Problemas principais.
- Hipóteses.
- Priorização de funcionalidades.
- Critérios de sucesso.
- MVP.

Comando sugerido:

“Analise esta ideia como um Product Manager. Identifique o problema principal, o público-alvo, as hipóteses, os riscos e as funcionalidades indispensáveis para o MVP.”

2. UX-UI-DESIGN

Objetivo:
Criar fluxos, wireframes e decisões de experiência.

Deve ajudar a definir:

- Fluxo de onboarding.
- Dashboard.
- Cadastro rápido de lançamento.
- Metas.
- Clubes.
- Desafios.
- Sistema de gamificação.
- Estados vazios.
- Mensagens de erro.
- Acessibilidade.

Comando sugerido:

“Crie a arquitetura de navegação e os wireframes textuais de um aplicativo mobile de controle financeiro gamificado.”

3. DATABASE-DESIGN

Objetivo:
Projetar o banco de dados corretamente.

Deve ajudar a definir:

- Usuários.
- Lançamentos.
- Categorias.
- Investimentos.
- Metas.
- Clubes.
- Membros.
- Desafios.
- XP.
- Conquistas.
- Conteúdos.
- Notificações.

Comando sugerido:

“Modele o banco de dados deste aplicativo, incluindo entidades, relacionamentos, índices, regras de integridade e histórico de alterações.”

4. FINANCIAL-CALCULATIONS

Objetivo:
Garantir que os cálculos financeiros estejam corretos.

Deve testar:

- Saldo mensal.
- Total de receitas.
- Total de despesas.
- Patrimônio líquido.
- Lucros e perdas.
- Percentual investido.
- Evolução mensal.
- Metas.
- Transferências internas.
- Valores negativos.
- Arredondamento.
- Moedas e centavos.

Comando sugerido:

“Crie testes unitários completos para os cálculos financeiros, incluindo casos extremos, lançamentos recorrentes, transferências e valores decimais.”

5. GAMIFICATION-DESIGN

Objetivo:
Criar uma gamificação equilibrada e saudável.

Deve definir:

- Regras de XP.
- Níveis.
- Conquistas.
- Missões.
- Sequências.
- Ranking.
- Recompensas.
- Proteção contra abuso.
- Critérios de consistência.

Comando sugerido:

“Projete um sistema de gamificação para controle financeiro que premie organização, aprendizado e consistência, sem incentivar competição baseada em renda ou patrimônio.”

6. SECURITY-PRIVACY

Objetivo:
Proteger os dados financeiros dos usuários.

Deve revisar:

- Autenticação.
- Autorização.
- Controle de acesso.
- Dados pessoais.
- Dados financeiros.
- Logs.
- Exclusão de conta.
- Exportação de dados.
- LGPD.
- Vazamento de informações entre clubes.

Comando sugerido:

“Faça uma auditoria de segurança e privacidade neste módulo. Procure falhas de autorização, exposição de dados financeiros e problemas relacionados à LGPD.”

7. TESTING

Objetivo:
Criar uma estratégia completa de testes.

Deve incluir:

- Testes unitários.
- Testes de integração.
- Testes de API.
- Testes de interface.
- Testes de cálculo.
- Testes de permissões.
- Testes de privacidade.
- Testes de acessibilidade.

Comando sugerido:

“Crie uma estratégia de testes para o MVP e implemente os testes mais importantes antes de adicionar novas funcionalidades.”

8. MOBILE-RESPONSIVE

Objetivo:
Garantir boa experiência em celulares e diferentes tamanhos de tela.

Deve validar:

- Layout responsivo.
- Formulários.
- Teclado numérico.
- Navegação inferior.
- Gráficos.
- Modais.
- Botões.
- Feedback visual.
- Modo escuro.
- Acessibilidade.

9. CONTENT-DESIGN

Objetivo:
Criar textos simples para educação financeira.

Deve ajudar a produzir:

- Artigos curtos.
- Explicações de conceitos.
- Microtextos.
- Mensagens de incentivo.
- Mensagens de erro.
- Missões.
- Questionários.
- Glossário.

Os conteúdos devem ser educativos, neutros e não devem funcionar como recomendação personalizada de investimentos.

10. CODE-REVIEW

Objetivo:
Revisar a qualidade do código continuamente.

Deve analisar:

- Bugs.
- Complexidade.
- Duplicação.
- Segurança.
- Performance.
- Padrões de arquitetura.
- Testabilidade.
- Nomenclatura.
- Acessibilidade.

Comando sugerido:

“Revise as alterações recentes procurando problemas funcionais, de segurança, performance e manutenção. Priorize problemas reais e apresente a gravidade de cada um.”
